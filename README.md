# Recetario familiar · lanzador

Página mínima instalable (PWA) que pone el Recetario familiar como aplicación con su propio icono en Android y Windows. No contiene recetas: al abrirla desde el icono lleva al recetario en claude.ai, que pide la sesión de Claude.

Instalación: abrir https://juanpueblaarjona-debug.github.io/recetario-app/ en Chrome (o Edge) y elegir «Instalar aplicación».
